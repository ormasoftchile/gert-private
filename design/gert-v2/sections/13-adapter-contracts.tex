\chapter{Adapter Contracts}

Gert v2 decouples the core runtime from presentation adapters (TUI, Web, VS Code) through explicitly versioned contracts. This section defines the concrete interface that adapters implement: event subscription API, initialization handshake, render lifecycle, and the non-negotiable constraint that adapters own no execution logic. This contract must be stable and extensible to support current and future adapters.
