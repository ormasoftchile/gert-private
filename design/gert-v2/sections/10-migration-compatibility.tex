\chapter{Migration and Compatibility}

Gert v2 is a breaking redesign from v1. This section specifies the migration path from \texttt{runbook/v0} and \texttt{runbook/v1} to the v2 schema, defines what `gert migrate` (v2 version) must accomplish, and establishes compatibility guarantees for existing runbooks.

Migration is a launch blocker for adoption: every operator with a v1 runbook must understand what breaks, what is automatically migrated, and what requires manual effort.
