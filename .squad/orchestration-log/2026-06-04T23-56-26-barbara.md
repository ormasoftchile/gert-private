## Design Decisions Made

### OQ1 — Short-circuit `and`/`or`
- **Status:** ✅ Ratified by ormasoftchile
- **Implementation:** Both `and` and `or` operators are short-circuiting.
  - `false and X` → `false` (X not evaluated)
  - `true or X` → `true` (X not evaluated)
- **Incorporated in:** GXL §3 (OrExpr, AndExpr), §5.1 semantics

### OQ2 — `capture.default:` scalar-only
- **Status:** ✅ Ratified by ormasoftchile
- **Implementation:** `capture.default:` is permitted **only for scalars** (null, boolean, number, string).
  - Subtree captures (object, array) MUST NOT declare a default.
  - Violation → `GCP-DEFAULT-SUBTREE` parse-time error.
- **Incorporated in:** GCP §6

### OQ3 — Portable JSON Value Model
- **Status:** ✅ Specified
- **Implementation:** PJVM types are `null`, `boolean`, `number` (float64), `string` (UTF-8), `array`, `object`.
  - No date, binary, undefined, int64, decimal, NaN, Infinity.
  - RFC 8259 strict subset.
- **Incorporated in:** GIS §4

### OQ4 — `list.indexOf` stdlib function
- **Status:** ✅ Added
- **Implementation:** `list.indexOf(l: list, item: scalar) → number`
  - Returns zero-based index of first match, or `-1` if not found.
  - `-1` sentinel aligns with Go/Java/C# conventions.
- **Incorporated in:** GXL §4.3

## Key Design Calls Documented

| Aspect | Decision | Rationale |
|--------|----------|-----------|
| **Identifier scope** | ASCII-only (`a-z`, `A-Z`, `0-9`, `_`) | Variable names from YAML keys + step IDs are ASCII by convention. Unicode admits spoofing risks. |
| **Number model** | IEEE 754 float64 + scientific notation | Matches Portable JSON Value Model. All runtimes support float64 natively. Scientific notation for thresholds (e.g., `1.5e-3`). |
| **GIS escape** | `\${` (not `$${`) | Stream A task spec. **Deviation from original proposal.** OI-GIS-01 flagged for team ratification (migration tool scope). |
| **GIS embedded expr** | Full GXL Expression (not just GDP) | Superset keeps grammar formally clean. Backward-compatible. |
| **GDP shared grammar** | Identical in GXL/GIS/GCP | Consistency in path resolution. `config.region` navigates same way in all three languages. |
| **exit_code spelling** | `exit_code` (snake_case, canonical) | GERT field naming convention. Don's audit flagged both `exitCode` and `exit_code`. OI-GCP-01: migration tool must convert. |
