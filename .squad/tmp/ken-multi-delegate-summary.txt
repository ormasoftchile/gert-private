MULTI-DELEGATE DESIGN — QUICK REFERENCE
========================================

REQUEST: "I need delegation to many" — multiple delegates, different tasks

SOLUTION: Add delegations: (plural) field

EXAMPLE:
--------
delegations:
  - delegate: {name: Son}
    assigns: [routine: trash_day, zone: garage]
  - delegate: {name: Daughter}
    assigns: [zone: garden]

KEY DECISIONS:
--------------
1. YAML DSL: delegations: (plural array) — each item = full delegation config
2. Model: Add Delegations []Delegation to PropertyFile
3. Conflict rule: LAST-WINS (array order)
4. Compiler: Each delegation → separate PolicyDefinition with indexed ID
5. Backward compat: Keep delegation: (singular) as syntactic sugar

CONFLICT RESOLUTION:
--------------------
If two delegations assign same routine → LAST in array WINS
Why: Simple, deterministic, debuggable

COMPILER OUTPUT:
----------------
Before: Delegation: &PolicyDefinition{ID: "prop.delegation"}
After:  Delegations: []*PolicyDefinition{
          {ID: "prop.delegation.0", ...},
          {ID: "prop.delegation.1", ...}
        }
