## Work Completed

### Schema Specification Update (§03)

- **Decision:** Removed generic `manual` step type
- **Replacement:** Three semantically precise step types:
  - `choice` — User selects from predefined options; stores result in variable
  - `decision` — User picks execution path; routes flow to selected runbook/step
  - `collector` — User provides unstructured input (text, files, images)

- **Specifications finalized:**
  - `choice`: prompt, options array, variable, optional default; min 2 options; unique values
  - `decision`: prompt, routes array, optional variable; min 2 routes; mutually exclusive runbook/goto
  - `collector`: prompt, fields array, optional approvals; supports text/multiline/file/image/url fields
