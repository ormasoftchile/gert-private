\chapter{Security and Trust}

\section{Trust Model}

\begin{itemize}
  \item Extensions are untrusted by default.
  \item Capabilities are least-privilege and explicit.
  \item Policy controls extension admission and operation.
\end{itemize}

\subsection{Runtime Hardening}

\begin{itemize}
  \item Host survives extension failure.
  \item Host enforces timeout, cancellation, and retry policy.
  \item Host logs structured diagnostics for extension interactions.
\end{itemize}
