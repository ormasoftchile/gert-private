## Summary

Webhook and event delivery baseline for GERT runbook execution events. V1→V2 roadmap established with phased capability progression. V1.0 baseline: per-execution webhook with retry + exponential backoff (5 attempts over 24h), summary events only (execution.started, step.completed, execution.finished, execution.failed), HMAC-SHA256 signing. DLQ handling for transient and extended customer endpoint outages. Upgrade path through tenant-level webhooks (v1.1), Azure Service Bus topics (v2.0), and Event Grid integration (v2.0).

## Baseline v1.0 Design

- **Delivery:** Retry + exponential backoff (5 attempts, 24h window)
- **Subscription:** Per-execution webhook URL
- **Events:** Summary only (< 1KB each)
- **Security:** HMAC-SHA256 + X-GERT-Signature header
- **Transient outage:** In-memory queue, exponential retry, → DLQ
- **Extended outage:** DLQ holds indefinitely, manual replay

## Rollout Phases

1. Sprint 1: Per-execution webhook + HMAC
2. Sprint 2: Retry/DLQ + admin replay
3. Sprint 3: Tenant-level registration
4. Sprint 4: Service Bus topics (v2.0 alpha)
5. Sprint 5: Event Grid (v2.0 beta)
